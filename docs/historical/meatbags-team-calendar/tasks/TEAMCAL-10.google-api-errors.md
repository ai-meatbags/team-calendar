# TEAMCAL-10 — Ошибка Google API: поведение UI и логирование

Статус: done

## Описание
Починить ситуацию, когда Google Calendar недоступен: сервер возвращает ошибку, UI показывает нескрываемое уведомление с крестиком (скрывается только по клику), скелетон исчезает и вместо слотов остаётся большой пустой блок.

Контекст ошибки (пример):
- API ответ: `{ error: "Calendar sync failed." }`
- Серверный лог: `response: undefined, error: FetchError: request to https://www.googleapis.com/calendar/v3/freeBusy failed, reason: read ECONNRESET`

## Критерии готовности
- При ошибке Google API в `availability` UI показывает заметное уведомление (toast/баннер) с крестиком.
- Уведомление не исчезает само, скрывается только по клику на крестик.
- При ошибке скелетон пропадает и остаётся большой пустой блок (без карточек слотов).
- Ошибка логируется на сервере и в клиентской консоли.
