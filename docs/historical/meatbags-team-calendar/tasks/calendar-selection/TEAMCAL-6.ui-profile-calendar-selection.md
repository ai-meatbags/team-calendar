# TEAMCAL-6 — UI: профиль и выбор календарей

Статус: todo

## Описание
Добавить UI для дефолтного выбора календарей.

## Критерии готовности
- Модалка “Календари” в профиле.
- GET `/api/me/settings` при открытии.
- PATCH `/api/me/calendar` при сохранении.

## Визуальная проверка
- Открыть профиль → “Календари”: список календарей виден, у primary стоит галка, остальные выключены.
- Переключить несколько чекбоксов → “Сохранить”: появляется тост успеха (Tailwind).
- Сделать ошибку (например, отключить интернет) → “Сохранить”: появляется тост ошибки (Tailwind), чекбоксы остаются.
- Обновить страницу и открыть “Календари” снова: выбранные ранее календари сохранены.
