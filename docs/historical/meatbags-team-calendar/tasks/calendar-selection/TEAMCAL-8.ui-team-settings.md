# TEAMCAL-8 — UI: настройки команды

Статус: done

## Описание
Добавить шестеренку и модалку настроек команды в React‑странице команды с разнесением UI на компоненты.

## Технические требования
- Реализовать UI в `frontend/src/pages/TeamPage.jsx`.
- Вынести связанные компоненты в `frontend/src/components/team/`.
- Контрол выбора календарей оформить отдельным компонентом (React).
- Шестеренка видна всем участникам и открывает модалку настроек команды.
- Данные для модалки загружаются через GET `/api/teams/:shareId/settings`.
- Поле имени команды доступно только owner (`canEditName` из ответа).
- При “Сохранить” отправлять PATCH `/api/teams/:shareId` с payload только `active` по calendarId.
- Успех/ошибка сохранения показываются через готовую систему тостов Tailwind.

## Критерии готовности
- UI вынесен в `frontend/src/pages/TeamPage.jsx` и `frontend/src/components/team/`.
- Шестеренка видна всем участникам.
- Название команды редактирует только owner.
- Чекбоксы календарей сохраняются в PATCH `/api/teams/:shareId`.
- Тосты показываются при успехе/ошибке сохранения.

## Тест кейсы
1. Открыть страницу команды участником (не owner) → видна шестеренка.
2. Нажать шестеренку → открывается модалка, подгружается список календарей.
3. Убедиться, что поле имени команды скрыто/disabled, если `canEditName = false`.
4. Отметить/снять чекбоксы → “Сохранить” → успех‑тост.
5. Перезагрузить страницу → открыть настройки → состояние чекбоксов сохранено.
6. Смоделировать ошибку API (например, отключить сеть) → “Сохранить” → ошибка‑тост, модалка не закрывается.
